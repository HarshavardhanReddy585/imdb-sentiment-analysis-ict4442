# Solo contingency plan

The canonical private repository is sufficient for the project. Teammates do not need to create separate repositories or change GitHub settings unless they are actively contributing code.

If a teammate contributes, request a repository URL, branch or commit, code, metrics, and contribution evidence. If they do not contribute, continue the model work in the canonical repository and do not create artificial teammate commits, signatures, or claims.

The final contribution statement should describe the actual work performed and should be submitted with faculty guidance if the team arrangement differs from the original plan.
